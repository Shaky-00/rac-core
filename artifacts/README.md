# Artifacts layout

Runtime experiment outputs are **gitignored**. Only small **expected** reference summaries are committed in this repository. They support cross-checking paper-reported counts; they are **not** a substitute for re-running data-dependent experiments without the external evaluation bundle.

| Path | Role |
|------|------|
| `rq1_tracebench/` | RQ1 paired/core TraceBench — **replay requires external paired data** |
| `rq2_baselines/` | RQ2 expanded baseline summary — **full replay requires expanded bundle** |
| `rq3_mcp_filesystem/` | RQ3 filesystem case study — **default verification uses expected JSON only** |
| `rq4_latency/` | RQ4 quick-latency reference — **not** the paper’s full 1248×20 overhead run |
| `expected/summaries/` | Compatibility aliases → same JSON as per-RQ `expected/` |
| `results/` | Local run outputs (`scripts/run_*.sh`); keep empty in git except `.gitkeep` |
| `generated/` | Reserved; unused in this artifact |

**Figures:** Paper Fig. 4 / Fig. 5 are not regenerated by scripts in this repository. Use the expected JSON files to verify reported metrics.

Each `rq*/README.md` describes the corresponding expected file. Do not commit large CSV/JSON under `results/`.
